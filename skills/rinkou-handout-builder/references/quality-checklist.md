# 輪講資料の品質チェックリスト

## 1. 担当範囲

- 原典PDFのファイルページと印刷ページの対応を記録したか。
- 指定された開始見出しから始まっているか。
- 指定された終了見出しの末尾まで含まれているか。
- 終了ページにある範囲外の次節を混入させていないか。
- ページをまたぐ文や段落が途中で消えていないか。
- 添削済みPDFがある場合、`scripts/extract_annotations.py`で全注釈を抽出し、件数とページを記録したか。
- ポップアップコメント、ハイライト、取り消し線の選択箇所を本文と対応づけたか。

## 2. 全文翻訳

- すべての本文段落が原典と一対一で対応するか。
- 見出し階層、例題、解答、注記を保持したか。
- 参考文献番号、脚注、付録・他節への参照を落としていないか。
- 図番号、式番号、本文中の参照先が一致するか。
- 訳者の解釈や追加説明を翻訳本文へ混在させていないか。
- 受動態と冗長表現を減らし、原文の意味を保った簡潔な日本語になっているか。
- 用語表を作り、本文、図、キャプション、解説で訳語を統一したか。
- 略語は初出で正式名称との対応を示し、2回目以降だけ略語へ統一したか。
- 略語を持たない語へ英語の括弧書きを付けていないか。
- カタカナへ写しただけの訳語を、定着した日本語の術語へ置き換えたか。
- 他の担当者の資料を参考にした場合、その書き方が添削指摘や研究室の規約に反していないか確認したか。

## 3. 数式

- 正負号、指数、複素単位、絶対値、添字が正しいか。
- 積分の上限・下限、微分変数、周波数と角周波数を取り違えていないか。
- 原典の式番号を必要に応じて保持したか。
- 本文から参照される番号がLaTeX上でも一致するか。
- `Hz`、`rad/s`、`dB`など、単位表記が標準的な記号で統一されているか。
- ディスプレイ数式を一つの文の途中へ挟まず、数式前で文を完結させたか。
- 数式の前後で同じ説明を重複していないか。

## 4. 図

- 原典の必要な図をすべて含めたか。
- 原著の図題・キャプションを含める場合は最後まで入り、除く場合は断片が残っていないか。
- 軸、凡例、添字、曲線、回路記号が欠けていないか。
- 英語ラベルの近くへ日本語を併記し、対応が図だけで分かるようにしたか。
- 図の下へ英日対応表を置いて、画像内への併記を省略していないか。
- ページ下部が半分以上空いていないか。空いている場合、図の配置指定が原因ではないか。
- 追加した日本語が曲線、軸、目盛、数式、回路記号を覆っていないか。
- 切り抜いた画像をLaTeXへ入れる前にReadで開き、意図した図が写っていることを確認したか。
- 最終PDFで図が空白になっていないか。
- 図の解像度と文字サイズは発表・印刷に耐えるか。
- 図がページ上端または下端へ自然に配置され、本文段落の間へ不自然に固定されていないか。
- 図だけのページや大きな空白を、不要な改ページや強制配置で作っていないか。

## 5. 独立解説

- 翻訳本文と見出し・改ページで明確に分離したか。
- 式や図が何を意味するかを説明しているか。
- 原理、直観、実装上の制約、例題結果の解釈のうち必要なものを補ったか。
- 原文の言い換えだけで終わっていないか。
- 輪講で口頭説明すべき要点が明確か。

## 6. PDF完成検査

- LaTeXを複数回実行し、相互参照を解決したか。
- ビルドログにエラー、未定義参照、未解釈の画像specialがないか。
- `pdfimages -list`の埋め込み画像数が想定と一致するか。
- 完成PDFをReadで開き、全ページを目視したか（20ページを超える場合は`pages`を分けて全ページ読む）。
- 余白、改ページ、図の位置、キャプション、ページ番号が適切か。
- `pdftotext`で開始箇所、終了箇所、例題、解説を検索できるか。
- 受動態、冗長表現、旧訳語、略語、綴り書き単位をGrepで全文検索したか。
- 初出表記を壊す一括置換や、部分一致による誤置換が残っていないか。
- 研究室の引用符・強調表記に従っているか。
- 添削PDFの全注釈を反映済み、対応不要、個別判断に分類し、未確認を残していないか。
